## About
Voxora AI is a college complaint management website that helps students, faculty, and administrators organize and track complaints about Wi-Fi, classrooms, laboratories, sanitation, hostels, transport, and maintenance. It suggests a category, priority level, and responsible department for each complaint, so urgent issues get attention sooner.

## Key Features
- **Complaint Submission:** Students and faculty submit complaints through a simple form.
- **Smart Classification:** Complaints are sorted into categories.
- **Priority Recommendation:** Each complaint is suggested as High, Medium, or Low.
- **Department Suggestion:** The responsible department is recommended.
- **Similar Complaint Warning:** Possible duplicates are flagged for administrator review. Nothing is deleted automatically.
- **Admin Dashboard:** Shows complaint counts and statuses (Pending, In Progress, Resolved) and lets administrators update them.

## How It Works
1. A complaint is submitted.
2. Category, priority, and department are suggested.
3. Similar complaints are flagged.
4. The administrator reviews it and updates the status.
